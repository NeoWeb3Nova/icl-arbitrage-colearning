## 信号甄别清单

收到一个信号时，快速检查：

- [ ] 真实性：数据源可靠？价差真实存在？
- [ ] 可执行性：流动性够吗？gas 合理吗？
- [ ] 风险：有没有 MEV 风险？合约安全吗？
- [ ] 时效：这个窗口还能持续多久？

## 执行决策框架

```
信号出现

  ├── 模拟验证：paper trading / 历史回测
  └── 严格控制实盘：小额、止损、记录
```
