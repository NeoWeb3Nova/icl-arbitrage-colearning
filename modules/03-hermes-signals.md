## 从观察到信号

### 信号类型框架

| 信号类型 | 数据源 | 触发条件 | 可重复性 |
|----------|--------|----------|----------|
| 价差信号 | DEX 报价 | 价差 > 阈值 | 高 |
| 流动性信号 | AMM 池深度 | TVL 变化 | 中 |
| 跨链信号 | Bridge 费率 | 费率异常 | 中 |
| 清算信号 | 借贷协议 | 健康因子 < 1 | 高 |
| MEV 信号 | Mempool | 大额交易 | 低 |

### 信号工作流设计

```
发现 → 记录(链/代币/数量/路径/成本) → 查询(历史/关联) → 告警 → 验证 → 执行/放弃
```

## 证据记录标准

每次观测记录：
- 时间戳
- 链 (Ethereum, Arbitrum, Optimism, Polygon, Base, etc.)
- 资产 (token address / symbol)
- 规模 (交易金额)
- 路径 (exact route)
- 预估成本
- 失败原因 (如果放弃)
