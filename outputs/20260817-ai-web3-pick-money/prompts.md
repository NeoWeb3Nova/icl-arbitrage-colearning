# Prompts

## Shared style suffix

Append this to every prompt:

```text
quirky hand-drawn editorial illustration, wobbly black ink lines, rough sketch texture, white or warm off-white background, soft blue as the main accent color, soft orange only for tiny warning highlights, concrete objects, clear visual storytelling, generous whitespace, slightly absurd but intelligent composition, not a formal infographic, not a PPT slide, not photorealistic, not 3D, not glossy, no gradients, no neon colors, no colored label boxes
```

## IMG-01 — MEV atomic arbitrage

```text
Create a 16:9 horizontal illustration about MEV atomic arbitrage on Ethereum.

Draw three concrete DEX liquidity pools connected by a black hand-drawn path inside a transparent blockchain block. A user transaction changes the price in one pool. An AI analysis window detects the temporary price difference. A small atomic arbitrage path buys on one pool and sells on another inside the same block. Show Gas and searcher competition as small deductions from the final result.

Use exactly three main stages: ① price change, ② opportunity detection, ③ atomic execution. Sparse handwritten Chinese labels only: “用户交易”, “价格偏差”, “原子套利”, “Gas”, “净收益”.

The message is: MEV profit comes from transaction ordering and precise execution, not magic. Do not make it look risk-free.
```

## IMG-02 — Base small-margin arbitrage

```text
Create a 16:9 horizontal illustration about the real economics of automated arbitrage on Base.

Place one tiny successful arbitrage result at the center labelled “$0.12”. Around it, show a cloud of approximately 350 faint failed transaction attempts. No giant money bag, no 100X, no celebratory trader, no green candle, no casino imagery.
```

## IMG-03 — MEV double edge


## IMG-05 — Bug bounty whitehat

```text

An ordinary security researcher uses an AI analysis window to inspect Solidity smart contract logic and trace protocol funds. In the center, show a transparent smart contract machine with one visible accounting connection error, but no funds being drained. On the right, show an authorized scope document and a reproducible bug report sent to a protocol team. After responsible disclosure and repair, show a reward envelope labelled “赏金”.

```
