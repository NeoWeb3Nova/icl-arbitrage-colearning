## Bruce 的使用思路

<!-- 摘自发起人原文 -->

> "这次我会让 Hermes 跟着整个学习过程一起工作。前期用它帮我找资料、读文档、解释概念和整理案例。等基础知识清楚一些，再让它调用工具、写查询和脚本，定时记录报价、Gas、滑点和路径变化。如果真的找到一个值得继续研究的方向，可以让它很快的帮我写验证脚本、回测脚本等。"

> "希望到时候也能产出一个链上套利专属的 Skills，可以方便快速检查机会和实施。"

## Hermes 在共学中的三个阶段

### 阶段 1: 研究助手（前期）
- 找资料、读文档
- 解释概念
- 整理案例

### 阶段 2: 数据引擎（中期）
- 调用工具和 API
- 写查询和脚本
- 定时记录: 报价、Gas、滑点、路径变化

### 阶段 3: 策略加速器（后期）
- 快速生成验证脚本
- 快速生成回测脚本
- 产出链上套利专属 Skills
