# 发起者链上套利第一性原理与套利地图整理

> 原始剪藏：`D:\ObsidianWorkspace\Neo\LLM-Wiki\raw\clippings\套利共学｜新手必读链上套利的第一性原理：从价差到可执行净利润.md`
>
> 本文整理发起者文章中的判断框架，作为项目研究资料。它不代表本人已经掌握，也不构成收益承诺或真实交易证据；具体路径仍须用真实报价、成本和失败条件验证。

## 1. 核心结论

套利不是单纯寻找两个不同价格，而是寻找同一经济价值在不同状态间尚未闭合的一致性，并构造可执行的资产闭环：

```text
起点状态 S₀
→ swap / bridge / mint / redeem / borrow / repay / liquidate / settle
→ 可与起点比较的终点状态 S₁
```

只有终点价值扣除全部成本、时间和风险后仍高于起点，屏幕价差才可能成为机会：

```text
净利润
= 逐腿按真实规模执行后的终点价值
- 起点价值
- 报价之外的协议费与 Gas
- 融资、跨链/赎回、竞争和失败成本
```

非原子路径还应评估：

```text
期望利润
= 成功概率 × 成功时利润
- 失败概率 × 失败时损失
- 资金与机会成本
```

一句话版本：

> 价差只是线索，资产闭环才是结构，全成本后的期望净利润才是机会。

## 2. 为什么“同一种资产”也未必具有同一经济价值

链上资产的具体状态至少包含：

```text
资产 × 市场 × 链 × 资产形态 × 时间 × 协议状态
```

例如 Ethereum 上的原生 USDC、新链上的桥接 USDC、中心化交易所账户中的美元余额，可能都接近 1 美元，但其赎回权、到账时间、对手方、桥风险和流动性不同。价格偏离可能是错误定价，也可能只是风险定价。

因此，判断路径前必须先确认起点和终点是否真的可比。若终点资产不可赎回、不可跨链、无法提现或流动性很差，账面盈利尚未闭环。

## 3. 从价差到交易的七步检查

1. **确定起点与终点**：明确从什么资产出发，最后回到多少同一经济价值。
2. **画出完整路径**：逐步列出买入、卖出、充值、跨链、等待、赎回和再平衡；任一步缺少退出通道，路径就未闭合。
3. **使用真实规模报价**：小额屏幕价不能代表实际成交；多跳路径必须按执行顺序计算每一腿。
4. **成本只扣一次，但不能漏扣**：有限规模报价通常已含池内手续费和价格影响；滑点是报价后状态变化造成的额外偏差，不能与报价已含成本重复计算。
5. **判断能否同时完成**：同链路径可能放入一笔交易原子执行；跨链、跨 CEX 或等待赎回的路径通常不能共同回滚，需要预置库存或计入敞口。
6. **模拟失败条件**：改变规模、Gas、最低输出、状态更新时间，并测试第二腿延迟、桥暂停、停止提现和价格继续偏离等情形。
7. **作出分级决策**：按证据依次选择放弃、观察、模拟交易或小额执行；实际执行后还要核对到账、费用、失败次数和库存变化。

## 4. 成本边界：避免漏算与重复扣除

有限规模执行报价通常已经反映：

- 池内交易费；
- 由本次交易规模造成的价格影响。

报价之外仍可能存在：

- Gas 与失败交易消耗；
- CEX 交易、充值、提现和资金调拨费用；
- 跨链、赎回和结算费用；
- 借贷利息、资金费率、保证金和融资成本；
- 报价后状态变化导致的额外滑点；
- 等待期间的价格变化、库存风险和资金占用；
- MEV、Gas 竞价或其他执行顺序竞争成本；
- 非原子路径的单腿成交、对手方和再平衡风险。

验证时必须注明哪些成本已进入报价，哪些是额外估算，避免把手续费、价格影响和滑点机械地重复扣除。

## 5. 按主要利润来源划分的 14 类套利

一条路径可能跨多个协议、市场和链。归类时只选择“利润最主要来自哪一种未闭合的价格关系”，其他部分放入执行路径与风险说明，避免重复分类。

| 类型 | 价差或收益来源 | 闭环方式 | 主要风险 | 发起者给出的新人友好度 |
|---|---|---|---|---|
| 跨中心化交易所 | 两个订单簿供需不同 | 两边预置库存，同时买卖后再平衡 | 深度、充提限制、交易所风险 | 中等 |
| 跨 DEX | 同链不同协议池状态不同 | 同链逐腿交换，可能原子完成 | 状态变化、Gas、排序竞争 | 低 |
| CEX–DEX | 链上与交易所更新不同步 | 两边预置库存并同时成交 | 两边不能共同回滚、托管与再平衡 | 较低 |
| 同一 DEX 不同池 | 费率档、版本或路由不同 | 协议内部换入再换出 | 价格影响、聚合器竞争 | 低 |
| 三角与多跳 | 多个相对价格未闭合 | A → B → C → A | 每腿改变后续池状态、Gas、竞争 | 低 |
| 跨链 | 资金不能及时跨链流动 | 跨链后卖出，或两链库存同步交易后再平衡 | 到账时间、桥、库存与非原子风险 | 低 |
| 铸造、赎回与资产形态 | 市价偏离协议转换价值 | mint、redeem、wrap 或 unwrap | 通道暂停、资格、额度、等待时间 | 中等 |
| 现货与到期合约基差 | 当前价与未来结算价偏离合理持仓成本 | 对冲后等待交割或收敛 | 保证金、借币、清算与交割规则 | 中等 |
| 永续资金费率 | 多空持仓需求不平衡 | 现货/永续或跨场所对冲并收取费率 | 费率反转、保证金与清算 | 中等偏低 |
| 利率与收益率 | 市场、期限或收益结构不同 | 借贷、持有到期或协议转换 | 收益变化、协议与流动性风险 | 中等 |
| 清算 | 协议为偿债提供奖励 | 偿债、接收抵押物、卖出并归还资金 | 预言机、Gas、价格影响与机器人竞争 | 低 |
| 拍卖 | 风险资产竞价低于外部可卖价值 | 竞拍后在外部市场变现 | 成交不确定、等待与卖出深度 | 低 |
| 订单流与状态变化 | 即将发生的交易改变链上状态 | 在目标状态变化后恢复价格 | 低延迟模拟、排序、bundle 与竞价 | 极低 |
| 消息、新闻与事件结算 | 可验证的转换、迁移或结算价值已改变 | 转换、结算或互补头寸 | 规则、资格、截止时间、争议与流动性 | 中等偏低 |

“新人友好度”是原文对公开数据、模拟和小额验证难度的定性判断，不是推荐等级，也不代表收益或机会频率。

## 6. 重要边界

### 原子执行不等于报价不会变化

同一 EVM 交易中的多步操作可以全部成功或全部回滚，但在交易进入区块前，池状态仍可能被其他交易改变，导致整笔交易失败或收益下降。

### 跨链调用不是全局原子交易

源链和目标链拥有独立状态机、区块与共识。一条链不能回滚另一条链已经确认的交易。桥接、锁定、退款和条件结算只能提供流程或经济层保障，不构成两条链底层状态的同步原子回滚。

### 收益率差和新闻不天然构成套利

页面 APY、资金费率或新闻只提供线索。若没有可验证的对冲、转换、到期或结算关系，最终价值仍取决于方向判断，就不是严格意义上的套利。

### 模拟通过不等于最终成交

模拟只证明路径在某个状态下可运行，不保证交易会被接收、打包、进入主链并最终确认。

## 7. 项目采用的机会检查卡

后续遇到候选机会时，至少填写以下字段：

```text
1. 起点状态与终点状态是否具有可比较的经济价值？
2. 主要价差来源是什么？为什么尚未闭合？
3. 完整执行路径是什么？每一步的退出通道是什么？
4. 真实输入规模下，各腿按顺序执行会得到多少？
5. 哪些费用和价格影响已进入报价？哪些成本尚未计入？
6. 路径能否原子完成？若不能，第一腿完成后留下什么敞口？
7. Gas、延迟、MEV、失败、资金占用和再平衡成本是多少？
8. 流动性容量和报价有效期是多少？
9. 最坏情况下会留下什么资产、债务或不可赎回头寸？
10. 当前结论属于：屏幕价差 / 理论毛利润 / 保守净收益 / 可执行机会 / 真实交易？
11. 决策是：放弃 / 观察 / 模拟交易 / 小额执行？否定条件是什么？
12. 可复现证据保存在哪里？
```

## 8. 对项目现有框架的影响

- 把“同一资产”升级为“可比较的同一经济价值状态”，补充链、资产形态、时间与协议状态维度。
- 把成本模型拆成“报价已包含”和“报价之外”两组，防止漏算或重复扣除。
- 非原子路径除保守净利润外，还要单独记录成功概率、失败损失、库存敞口和机会成本。
- 套利分类按主要利润来源归类，协议、工具、市场与链仅作为执行维度。
- 后续研究必须区分屏幕价差、理论毛利润、保守净收益、可执行机会和真实已完成交易。
