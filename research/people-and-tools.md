# 链上套利学习榜样与工具资料

> 来源范围：发起者 2026-08-02 最新说明中明确提及的人物与工具，以及这些对象的公开主页、代表性公开内容和官方文档。
>
> 筛选原则：学习可复用的方法与证据，不追随收益截图，不把任何人物或工具当作收益背书。

## 先看结论

这篇文章真正值得收集的不是“大佬名单”，而是四种能力样本：

1. Bruce Xu：把熊市当成基础设施建设期。
2. Vida：用监控、警报和对冲思维提高机会响应能力。
3. shep：保持独立判断，减少被群聊和 KOL 共识污染。
4. Aliez Ren：把双边执行工程化，同时明确区分“操作工具”和“盈利策略”。

工具链则对应一条完整研究流水线：

```text
LI.FI 报价/路由 + The Graph 历史数据 + RPC 实时链上状态
                    ↓
              Hermes / 推理模型
                    ↓
       来源核对、成本补齐、回测、监控、复盘
                    ↓
       Taoli Tools 等半自动执行工具（后置，不先接真钱）
```

## 人物与学习样本

### 1. Bruce Xu（@brucexu_eth）

公开简介显示，他从事 AI × Ethereum FDE / DevRel，并在 LI.FI、LXDAO、ETHPanda 与 Hermes Agent 等方向活动。[2] 在最新共学说明中，他强调熊市先补原理、数据源、脚本和监控；市场转热后再针对资产、链、路径和策略快速微调。[1]

**值得学习**

- 基础设施先于机会：平时把数据、脚本和评估流程准备好。
- 自己设计学习路线：AI 负责拆解和加速，人负责目标与判断。
- 证据优先：真实报价、完整成本、失败条件和复盘比截图重要。
- 公开学习筛选长期合作者：持续行动本身就是能力证明。

**我们怎么学**

- 每日只要求一个真实样本，但必须记录时间、链、资产、金额、路径和完整成本。
- 每周保留一个“为什么不做”的案例，训练放弃能力。
- 把 Hermes 训练成候选机会检查器，而不是喊单机器人。

### 2. Vida（@Vida_BWE）

Vida 的公开简介将自己描述为 prop trading firm founder；当前账号内容受保护，因此不能把不可见内容当作可核验策略资料。[3] 搜索引擎仍索引到两条与本文相关的历史公开内容：一条复盘提到为小币价格异动和现货/合约巨大价差设置强制警报；另一条提到 delivery-perp / funding arbitrage。[4][5]

**值得学习**

- 机会不是靠一直盯盘，而是靠有阈值的监控与强提醒。
- 资金费率套利不是只看费率，还要同时看现货/合约价差、流动性和退出条件。
- 真正的 Edge 可能来自响应系统、执行纪律和组织能力，而不只是公式。

**证据边界**

- 目前只能确认公开简介与被搜索索引的历史片段，不能据此重建完整策略、收益或风险参数。
- 观察重点应是监控方法，不是复制具体仓位。

### 3. shep（@shep_eth）

发起者把 shep 列为擅长套利思维的学习对象。[1] shep 的公开主页可确认账号身份；其近期公开内容强调，超额收益往往来自“与众不同且正确”的观点，并建议减少群聊和 KOL 内容对独立思考的影响。[6][7]

**值得学习**

- 先形成自己的假设，再看市场共识，避免把别人观点误当证据。
- 把“不同”与“正确”拆开：不同不是 Edge，经过数据验证的不同才可能是 Edge。
- 控制信息摄入，减少追热点导致的策略漂移。

**证据边界**

- 本轮公开检索没有找到可独立验证的 shep 套利策略、链上地址或完整案例。
- 因此暂时把他归为“独立判断样本”，不归为可复制策略源。

### 4. Aliez Ren（@aliez_ren）

Aliez Ren 的公开主页直接指向 Taoli Tools。[8] 他对产品边界的公开说明很重要：Taoli Tools 本质是双边下单辅助工具，不包含策略、没有收益率承诺，付费用户有亏有赚，而公开晒单天然偏向盈利案例。[9]

**值得学习**

- 把高风险、易出错的双边操作压成一致执行流程。
- 明确“发现策略”和“执行策略”是两层能力。
- 对收益展示保持样本偏差意识。
- 工具价值可以来自减少手误、统一监控和缩短执行时间，而不是预测市场。

**我们怎么学**

- 先研究其交互、监控字段和风险提醒，不立即接入真钱账户。
- 用 Paper Trading 复刻双边开仓、仓位平衡、资金费率和退出条件。
- 只有在权限、密钥、最大亏损和异常退出都核验后，才讨论小额实盘。

## 工具资料与项目用途

### LI.FI API / SDK

LI.FI 的 SDK 提供 `getRoutes` 与 `getQuote`。路由请求可指定源/目标链、代币和金额；选项包括最大价格冲击、最快/最便宜排序、滑点、桥和交易所偏好等。[11]

**在本项目中的作用**

- 采集同一资产在不同时间、链、金额下的 Route / Quote。
- 保存预计到手数量、Gas、桥、DEX、中间资产、执行时间和价格冲击。
- 比较 `CHEAPEST` 与 `FASTEST`，研究收益与时间风险的交换。

**第一份最小数据集**

- 固定一个源资产、一个目标资产。
- 选择 2 条源链、2 条目标链、3 个金额档位。
- 每次保存原始响应和标准化成本字段，不执行交易。

### The Graph

The Graph 官方文档把 Subgraphs 定义为提取、处理和查询链上数据的开放 API；Substreams 用于实时与历史数据流，Graph Node 负责索引并通过 GraphQL 提供查询。[12]

**在本项目中的作用**

- 查询历史 Swap、流动性、交易量与池状态。
- 还原公开套利案例发生时的市场背景。
- 为回测提供结构化历史样本，而不是手工翻区块浏览器。

**边界**

- Subgraph 的 schema、同步高度和索引逻辑决定了能看到什么。
- 关键结论仍需用 RPC、交易回执或区块浏览器交叉核验。

### RPC / 节点

RPC 是实时读取区块、日志、交易回执、Gas、合约状态和池状态的底层入口。The Graph 适合结构化查询，RPC 适合最终事实核验；两者不是替代关系。

**在本项目中的作用**

- 验证交易是否上链、是否回滚、实际 Gas 使用和最终事件。
- 读取当前池状态，避免历史索引延迟被误当实时机会。
- 对关键样本保留区块号、交易哈希和链 ID。

### Hermes Agent

Hermes 官方文档说明其具备工具调用、记忆、Skills、定时任务、子代理与 MCP 等能力。[13]

**在本项目中的作用**

- 研究：检索来源、拆概念、还原案例。
- 数据：生成采集脚本、标准化字段、定时记录报价。
- 策略：补齐成本、检查流动性与限制、生成回测或模拟。
- 复盘：把失败原因沉淀为可复用检查清单和套利 Skill。

**边界**

- Agent 的结论必须引用真实数据，不能用语言流畅度代替证据。
- 私钥、助记词和交易所密钥不进入提示词、记忆、日志或仓库。
- 自动采集可以先做；自动实盘不属于第一阶段目标。

### ChatGPT 5.6-Sol xhigh

这是发起者原文中推荐的推理配置名称。[1] 本轮未找到可用于独立核验该名称的官方公开产品页，因此只按原文记录，不扩写未经证实的产品规格。

**适合用途**

- 对复杂策略做第一性原理拆解。
- 生成反证问题、失败路径和验证计划。
- 与 Hermes 分工：模型负责推理草案，Hermes 负责调用工具、落盘、调度和持续工作流。

### Taoli Tools

官方手册将 Taoli Tools 定义为本地运行的半自动 U 本位对冲套利工具，支持一键双边反向下单、跨所价差、永续资金费率套利以及价格、价差、持仓、资金费和风险监控。[10] 官方同时明确它不是无风险摇钱树、不能全自动赚钱、不能自动执行策略，并警告用户可能损失全部本金。[10]

**在本项目中的作用**

- 学习双边下单和仓位对冲的操作模型。
- 对照其监控字段设计我们的机会记录 schema。
- 在 Paper Trading 阶段研究异常场景：单腿成交、延迟、价差收敛、资金费变化和退出失败。

**安全门槛**

- 初期只读文档与界面，不填真实密钥。
- 如需测试，使用独立账户、最小权限、禁止提现、IP 白名单和可承受的小额资金。
- 工具本地运行不等于零风险；浏览器、依赖、设备和交易所 API 权限仍是攻击面。

## 学习优先级

| 优先级 | 对象 | 现在做什么 | 暂时不做什么 |
|---|---|---|---|
| P0 | Bruce 的方法 | 落实三周路线与证据打卡 | 不把“套利长期存在”理解为保证盈利 |
| P0 | LI.FI | 采集 Routes / Quotes | 不直接执行跨链交易 |
| P0 | The Graph + RPC | 历史查询与事实核验 | 不先自建完整索引基础设施 |
| P0 | Hermes | 建候选机会检查工作流 | 不做无人值守实盘 |
| P1 | Vida | 学监控、阈值与告警 | 不复制仓位或收益截图 |
| P1 | shep | 建独立假设与信息卫生 | 不把观点当策略证据 |
| P1 | Aliez | 学执行工程与产品边界 | 不把工具当策略 |
| P2 | Taoli Tools | 文档研究与 Paper Trading | 未过安全门槛前不接真钱账户 |
